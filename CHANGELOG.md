# Изменения

## В разработке

- Опубликован пакет `alol` в AUR; добавлены инструкции установки через yay/paru.
  Для открытия ссылок и папок явно указана зависимость `xdg-utils`.

## 1.0.1

- Добавлен AppImage x86_64 с библиотеками GTK и обновлением из окна ALOL.

- Добавлены свободные шрифты с кириллицей для меню F11 (AZRTC): недостающие
  файлы Segoe UI в префиксе заменяются файловыми псевдонимами Google Sans.
  Существующие шрифты и системные настройки не меняются.
- Исправлена ложная ошибка «Не найдены Lua-библиотеки: inicfg» при добавлении
  Lua-модов: `inicfg` встроена в MoonLoader и не требует отдельного файла.
  Проверка наличия MoonLoader и внешних библиотек сохранена.
- Исправлены ложные ошибки для встроенных модулей LuaJIT `jit.util`, `jit.opt`
  и `jit.profile`; добавлено распознавание библиотек с `init.luac`.
- Проверка Lua учитывает комментарии между `require` и аргументом, длинные
  строковые литералы и регистр имени папки MoonLoader. Вычисляемые имена
  библиотек и методы объектов больше не создают ложные зависимости.
- При распаковке сохранены папки `LIB`, `Config` и ресурсов независимо от регистра,
  чтобы их содержимое не выпадало из своих каталогов.
- Ручной выбор MoonLoader, CLEO или Mod Loader больше не дублирует папку
  загрузчика, если она уже есть в архиве.

## 1.0.0 — первый стабильный релиз

- В окне «О проекте» добавлены ссылки на GitHub Velmi1337, сайт автора и Telegram @alolinux.

- Настройки разделены на «Игра», «Запуск», «Лаунчер» и «Помощь» с вкладками MD3.
  Каталог, установленные моды и импорт архива показываются отдельно. Списки
  используют доступную высоту, действия закреплены снизу; выбор сохраняется
  после обновления, а кнопки управления учитывают состояние выбранного мода.
- Журнал получил поиск, фильтр ошибок и предупреждений, выбор последней операции
  или всего доступного журнала, паузу и автопрокрутку. Копируются видимые записи.
  Терминальные коды и перезаписываемые строки прогресса убраны из отображения;
  операции подписаны датой, игрой и результатом.
- Добавлены «Очистить» в журнале и `alol logs-clear`: текущий журнал обнуляется,
  архив удаляется, посторонние файлы не затрагиваются. Обнуление сохраняет
  открытый дескриптор, поэтому текущий процесс может продолжать запись.
- Интерфейс приближен к Pixel: Google Sans с кириллицей, спокойная голубая палитра,
  светлая и тёмная темы с мгновенным применением, сгруппированные строки настроек
  и переключатели. Готовый главный экран показывает сервер и персонажа без
  приветственного баннера. Обновления собраны в настройках.
- Переключатели и память игры сохраняются сразу; панель сохранения появляется
  только при изменении путей или окружения. Добавлены Ctrl+Enter, Ctrl+1…4 и поиск
  модов по мере ввода. Смена темы сохраняет незавершённые правки путей в интерфейсе.
- Google Sans v14.000 встроен без изменений под OFL-1.1; лицензия и авторство
  сохранены в NOTICE и доступны через `alol --license`. Шрифт подключается только
  внутри ALOL, без установки в систему. Код приложения остаётся Apache-2.0.
- Интерфейс полностью переработан по Material 3 Expressive для GTK: боковая
  навигация с компактным горизонтальным вариантом, тональные поверхности,
  выразительные формы карточек и кнопок, единые стили полей, списков, меню
  и окна обновления. Главное действие и сохранение остаются на экране.
- У Родины убраны ввод и проверка никнейма: персонаж выбирается внутри игры.
  Как в официальном лаунчере, для запуска используется случайное служебное
  имя `Player_…`. Старые ники удаляются только из профиля Родины в ALOL;
  настройки аккаунта официального лаунчера и профили Arizona сохраняются.
- Добавлен переключатель Arizona RP / Родина RP над содержимым. Запуск, серверы,
  графические настройки, каталоги и установка модов, откат и
  восстановление учитывают выбранную игру. Общие Proton/Wine и официальный
  установщик используются для обеих игр.
- Родина запускается с параметром `-rodina`, собственными адресами серверов и
  ресурсами модов. Поддерживается её папка установки из официального лаунчера.
  Официальный лаунчер открывает выбранную игровую вкладку.
- Настройки и ники Arizona сохраняют прежние пути; выбор сервера и настройки Родины хранятся
  отдельно. Переключение сохраняет изменения, а на время игры и операций оно
  отключается. Сброс `rodina.set` не затрагивает настройки Arizona.
- Добавлены отдельные desktop identity и значок Родины. Исправление раскладки,
  показ FPS и GameMode работают для обеих игр. CLI поддерживает `alol project`
  и временный выбор `--project rodina` для конкретной команды.

## 0.5.8

- Исправление индикатора EN/RU объединено с профилем Arizona в ALOL-Proton 0.1.0.
  Кнопка подготовки скачивает готовые DLL и полные изменённые исходники Wine
  с проверкой SHA256; компилятор пользователю не нужен. Старые runtime сохраняются.
- Добавлено исправление индикатора
  раскладки Arizona. Запросы GetKeyboardLayout / GetKeyboardLayoutName получают
  язык текущей XKB-карты через отображение памяти; опроса на каждом кадре нет.
  ru-RU, Windows-1251 / OEM 866 и обработка WASD сохранены. Помощник наблюдает
  смену группы и замену карты, не читает вводимый текст и не меняет системную
  раскладку. При его отключении возвращается обычное поведение Wine.
  Пересобраны только user32.dll для 32/64 бит; полные исходники Wine и инструкция
  прилагаются к отдельной версии, прежний экспериментальный Proton сохраняется.
- Исправлена передача русской локали через UMU/Proton: `HOST_LC_ALL` сохраняет
  ru-RU и кодовые страницы при унаследованном `LC_CTYPE=C.UTF-8`.

- Убраны периодические обходы всей папки игры в простое: новые Windows-метки
  отслеживаются через inotify, события обновлений объединяются. При потере
  уведомлений сохраняется резервная проверка. Журнал GTK перечитывается только
  при изменении файла, с обработкой ротации и обнуления.
- Добавлен экспериментальный ALOL-Proton: отдельный пакет на базе закреплённого
  GE-Proton11-11, проверка SHA256, безопасная распаковка и слой запуска Arizona.
  Подготовка и выбор доступны из настроек и `runtime-prepare [--select]`.
  DXVK и обработка игровых клавиш сохранены; преимущество по FPS не заявляется.
- Для окон Arizona добавлена отдельная оранжевая иконка AZ; у ALOL остаётся фиолетовая.
  При обновлении desktop-метаданных сохраняется команда запуска установленной копии.
- Добавлены показ FPS / времени кадра DXVK и необязательный запуск игры через
  установленный GameMode. Удалены экспериментальные пресеты ухудшения графики,
  лимит FPS, VSync и обход Alt+Tab; их старые настройки больше не применяются.
- Добавлен отдельный сброс web-кэша Arizona с резервной копией.
- Импорт модов разбирает смешанные и вложенные архивы, папки Lua-библиотек и
  конфигураций. Есть проверка плана, поиск загрузчиков в официальном каталоге,
  статическая проверка строковых require и учёт общих библиотек при откате.
  Для скомпилированных скриптов явно показывается ограничение проверки зависимостей.
- Текущая ветка переведена с MIT на Apache-2.0. Добавлен NOTICE с авторством.
- LICENSE и NOTICE включаются в исходники, пакеты, локальную установку и файлы
  отдельного бинарника. Команда `alol --license` выводит оба встроенных документа.
- Обновлены метаданные лицензии и проверки релизной упаковки. Ранее опубликованные
  теги и файлы релизов сохраняют прежнюю лицензию и не заменяются.

## 0.5.7

- Рабочая копия запускается через `run-dev.sh` с отдельными данными `.dev-data`.
  Она не устанавливает бинарник в систему и не обновляет себя релизным файлом.
- Для окна разработки добавлен ID `alol-dev` со скрытой desktop-записью.
  Arizona получает отдельный UMU GAMEID вместо общего `steam_app_default`.
- Переработаны экраны игры, настроек, модов и журнала: закреплённые действия,
  понятные этапы установки, группы настроек, подсказка о сохранении изменений,
  восстановление через раздел помощи и копирование журнала.

## 0.5.6

- Убрана остановка установки при отсутствии системной `ru_RU.UTF-8`.
  Локаль создаётся в пользовательских данных ALOL через `localedef --no-archive`,
  применяется только к Wine/UMU/winetricks и обновляется вместе с версией glibc.
  Если генерация недоступна, используется встроенная обработка ru-RU в Wine.
- Убрана зависимость RPM от системного русского языкового пакета.
- Добавлен отключаемый режим совместимости клавиатуры для COSMIC:
  XWayland при наличии DISPLAY, отключение Linux IME и per-EXE UseXIM для игры.
  Системная раскладка и привязки GTA не меняются. Есть резервная копия реестра.
- Проверены повтор установки после ошибок, сохранение компонентов и кэша,
  настоящая локаль glibc и кодировки в отдельном Wine-префиксе.
- В README добавлен Contributors: Velmi1337 и Codex (ИИ-помощник OpenAI).

## 0.5.5

- Проверка обновлений по умолчанию выполняется при каждом запуске. В настройках
  доступны ежедневный, еженедельный и ручной режимы, а также отключение окна уведомления.
- Добавлено окно обновления с описанием релиза, кнопками установки и перезапуска.
  Во время игры уведомление откладывается; настройки проверки сохраняются сразу.
- Для официального лаунчера добавлен отключаемый режим совместимости:
  чистое окружение без конфликтующих переменных dotfiles/оверлеев и XWayland.
  После аварийного завершения возможна одна повторная попытка без GPU.
- Добавлены PNG-иконка, встроенная иконка окна и единая desktop identity.
  Для запуска из исходников создаётся пользовательская запись, если ALOL ещё не установлен.
- Начальный размер ограничен рабочей областью монитора. Раздел обслуживания
  изначально свёрнут; дублирующая кнопка установки официального лаунчера удалена.

## 0.5.4

- Исправлены нечитаемые меню и списки на COSMIC и светлых GTK-темах:
  явные цвета всплывающих окон, диалогов, стрелок и разделов обслуживания.
- Заголовок окна больше не наследует крупный шрифт заголовков приложения.
  Главный экран уплотнён, чтобы основные действия помещались в обычном окне.
- Добавлены автоматическая проверка обновлений при запуске, кнопки установки
  и перезапуска, а также команды `check-update` и `self-update`.
- Обновление проверяет размер и SHA256 из GitHub Releases. Пакеты обновляются
  через pacman/dnf с системным запросом прав; локальная копия заменяется атомарно.
- В релиз включён отдельный x86_64-бинарник для локальных обновлений.

## 0.5.3

- Добавлены RPM и установщик для Fedora 44+ x86_64, сборка и установка пакета
  проверяются в чистой Fedora через GitHub Actions.

- Публикация загружает RPM и отдельные контрольные суммы после успешного CI.
