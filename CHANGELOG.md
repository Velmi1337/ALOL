# Изменения

## 0.5.7

- Рабочая копия запускается через `run-dev.sh` с отдельными данными `.dev-data`.
  Она не устанавливает бинарник в систему и не обновляет себя релизным файлом.
- Для окна разработки добавлен ID `alol-dev` со скрытой desktop-записью.
  Arizona получает отдельный UMU GAMEID вместо общего `steam_app_default`.
- Переработаны экраны игры, настроек, модов и журнала: закреплённые действия,
  понятные этапы установки, группы настроек, подсказка о сохранении изменений,
  восстановление через раздел помощи и копирование журнала.

## 0.5.6

- Убрана остановка установки при отсутствии системной `ru_RU.UTF-8`.
  Локаль создаётся в пользовательских данных ALOL через `localedef --no-archive`,
  применяется только к Wine/UMU/winetricks и обновляется вместе с версией glibc.
  Если генерация недоступна, используется встроенная обработка ru-RU в Wine.
- Убрана зависимость RPM от системного русского языкового пакета.
- Добавлен отключаемый режим совместимости клавиатуры для COSMIC:
  XWayland при наличии DISPLAY, отключение Linux IME и per-EXE UseXIM для игры.
  Системная раскладка и привязки GTA не меняются. Есть резервная копия реестра.
- Проверены повтор установки после ошибок, сохранение компонентов и кэша,
  настоящая локаль glibc и кодировки в отдельном Wine-префиксе.
- В README добавлен Contributors: Velmi1337 и Codex (ИИ-помощник OpenAI).

## 0.5.5

- Проверка обновлений по умолчанию выполняется при каждом запуске. В настройках
  доступны ежедневный, еженедельный и ручной режимы, а также отключение окна уведомления.
- Добавлено окно обновления с описанием релиза, кнопками установки и перезапуска.
  Во время игры уведомление откладывается; настройки проверки сохраняются сразу.
- Для официального лаунчера добавлен отключаемый режим совместимости:
  чистое окружение без конфликтующих переменных dotfiles/оверлеев и XWayland.
  После аварийного завершения возможна одна повторная попытка без GPU.
- Добавлены PNG-иконка, встроенная иконка окна и единая desktop identity.
  Для запуска из исходников создаётся пользовательская запись, если ALOL ещё не установлен.
- Начальный размер ограничен рабочей областью монитора. Раздел обслуживания
  изначально свёрнут; дублирующая кнопка установки официального лаунчера удалена.

## 0.5.4

- Исправлены нечитаемые меню и списки на COSMIC и светлых GTK-темах:
  явные цвета всплывающих окон, диалогов, стрелок и разделов обслуживания.
- Заголовок окна больше не наследует крупный шрифт заголовков приложения.
  Главный экран уплотнён, чтобы основные действия помещались в обычном окне.
- Добавлены автоматическая проверка обновлений при запуске, кнопки установки
  и перезапуска, а также команды `check-update` и `self-update`.
- Обновление проверяет размер и SHA256 из GitHub Releases. Пакеты обновляются
  через pacman/dnf с системным запросом прав; локальная копия заменяется атомарно.
- В релиз включён отдельный x86_64-бинарник для локальных обновлений.

## 0.5.3

- Добавлены RPM и установщик для Fedora 44+ x86_64, сборка и установка пакета
  проверяются в чистой Fedora через GitHub Actions.
- Для новой конфигурации автоматически выбирается доступный Wine, если нет UMU;
  существующие настройки и префиксы не переключаются автоматически.
- RPM проверяется на состав файлов, владельцев и обезличенные метаданные сборки.
- Публикация загружает RPM и отдельные контрольные суммы после успешного CI.

## 0.5.2

- Добавлены скриншоты настоящего интерфейса и отдельный режим съёмки с временным
  демо-профилем без доступа к личным данным и без запуска игры.

- Выровнены кнопки: одинаковая высота, равные колонки действий и общая ширина
  кнопок рядом с полями. Обслуживание собрано в сетку из двух колонок.
- Вкладки занимают одинаковую ширину; обновлены состояния наведения и фокуса.

## 0.5.1

- Добавлены установщик Arch Linux/CachyOS, пакет pacman и проверяемые SHA-256.
- Исходники упаковываются по явному списку; нормализуются владельцы файлов
  и метаданные пакета, исключён инвентарь программ машины сборки.
- Подготовлены проверка артефактов перед публикацией и GitHub Release.

- Удалён экспериментальный автопароль: поле ввода, помощник Moonloader,
  автоматическая установка его зависимостей и передача данных при запуске.
- Профили версии 0.5.0 очищаются от сохранённых паролей; никнеймы и серверы сохраняются.
  Удаляются только служебные файлы прежнего помощника ALOL.
- Сохранены игровые настройки Arizona и менеджер модов.
- Упрощены документация и интерфейс, добавлены исключения для локальных данных и кэшей.
- Добавлена команда `alol --version`.
