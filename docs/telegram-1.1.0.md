**ALOL 1.1.0 — установка и обновление игр прямо из лаунчера**

Теперь Arizona RP и Родину RP можно установить и обновить из одного окна ALOL. Лаунчер скачивает только необходимые файлы и продолжает загрузку после остановки. Официальный лаунчер Arizona доступен отдельной кнопкой.

**Что ещё нового**

- Проверка игровых обновлений идёт в фоне, пока запускается игра. Если вышла новая версия, ALOL покажет подсказку рядом с «Обновить игру».
- При установке видно, на каком этапе находится загрузка и сколько данных осталось. Запуск через уже готовый Steam Runtime быстрее проходит проверку UMU.
- В оформлении теперь шесть акцентных цветов, размер текста до 120% и нижняя панель навигации.

**Где скачать**

ALOL доступен в AUR как `alol` для Arch Linux и CachyOS. Установить можно командой `yay -S alol` или `paru -S alol`. На GitHub есть AppImage, готовый пакет Arch/CachyOS и RPM для Fedora 44+.
