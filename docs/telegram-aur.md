**ALOL теперь доступен в AUR**

Лаунчер Arizona RP и Родины RP для Linux можно установить из AUR под именем **alol**.

Через yay:
```sh
yay -S alol
```

Или через paru:
```sh
paru -S alol
```

Пакет собирается из исходников стабильного релиза 1.0.1. Зависимости для сборки и запуска установит AUR-помощник. Нужны включённый multilib и base-devel.

Обновления приходят вместе с остальными AUR-пакетами: `yay -Syu` или `paru -Syu`. Настройки и игровые профили сохраняются.

Также доступны AppImage и готовые пакеты Arch/CachyOS и Fedora.
