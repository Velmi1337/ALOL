🛠 **ALOL 1.0.1 — исправления по вашим отзывам + AppImage**

Небольшое обновление лаунчера Arizona RP и Родины RP для Linux.

🔤 **Русский текст в меню F11**
Исправлена проблема со шрифтами AZRTC, из-за которой вместо надписей появлялись `????`. Исправление работает и для существующих профилей — после обновления перезапустите игру.

🧩 **Надёжнее установка модов**
Убраны ложные ошибки про отсутствующие `inicfg` и встроенные библиотеки LuaJIT. Исправлены обработка зависимостей, распаковка папок библиотек и ресурсов и установка архивов с готовой структурой MoonLoader/CLEO/Mod Loader.

📦 **Теперь есть AppImage**
Скачайте файл, разрешите запуск и откройте. Библиотеки интерфейса уже внутри; обновления доступны из самого ALOL. Для Linux x86_64 с glibc 2.35+ (Ubuntu 22.04 и новее). Для игры по-прежнему нужны Wine или UMU/Proton и драйверы.

💾 Настройки и профили сохраняются. Пакеты Arch/CachyOS и Fedora тоже доступны.
